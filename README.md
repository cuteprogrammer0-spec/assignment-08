# 🐄 QurbaniHat - Premium Livestock Marketplace

**QurbaniHat** is a modern, high-performance web application designed to simplify the process of buying and selling livestock for the Qurbani season. Built with a focus on premium user experience, it features ultra-modern interactions, glassmorphism UI, and seamless authentication.

## 🌐 Live URL
qurbanihatt.netlify.app

## 🚀 Key Features

*   **Premium UI/UX:** Built with a glassmorphism design language, featuring floating navigation and high-quality livestock imagery.
*   **Secure Authentication:** Integrated with Firebase Auth for Email/Password and Google Social Login.
*   **Dynamic Animal Listings:** Users can browse a wide variety of animals with real-time data updates.
*   **Modern Interactions:** Smooth scroll-reveal animations and interactive hover effects powered by Framer Motion.
*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop devices for a seamless experience on any screen size.
*   **User Dashboard:** Personalized welcome and easy access to animal management features.

## 🛠️ Technologies & Packages Used

### Core Frameworks:
*   **React.js**: Front-end library for building the user interface.
*   **Tailwind CSS**: Utility-first CSS framework for rapid styling.
*   **DaisyUI**: Tailwind CSS components for a clean and consistent UI.

### NPM Packages:
*   **firebase**: For backend services including Authentication and Firestore.
*   **react-router-dom**: For handling single-page application routing.
*   **framer-motion**: For advanced scroll and entrance animations.
*   **react-hot-toast**: For beautiful, non-blocking notifications.
*   **lucide-react** / **react-icons**: For modern and scalable iconography.
